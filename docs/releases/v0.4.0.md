# v0.4.0 — MIT 公开开源版：干净原创综合报告与离线交互展示台

本版本是「跨平台网络隐私与本机环境工具包」的首个 **MIT 公开开源版本**。

## 变更要点

- **MIT 开源与干净的版权边界**：新增 [LICENSE](https://github.com/rumpelpalmour757-lgtm/cross-platform-privacy-environment-kit/blob/v0.4.0/LICENSE)（MIT，Copyright (c) 2026 Celeste）与 [THIRD-PARTY-NOTICES.md](https://github.com/rumpelpalmour757-lgtm/cross-platform-privacy-environment-kit/blob/v0.4.0/THIRD-PARTY-NOTICES.md)；彻底移除此前私有版本中的第三方原文镜像与微信文章，并重建干净的提交历史。
- **干净原创的跨端综合报告**：把全部跨端网络边界、独立四层实测数据（CLI 冷启动归零实测、Desktop `6.28899.6` MSIX 防火墙自动放行冲突、39 目标路由对账）、五大常见误区纠偏与防护落地映射整理为单份独立文档 [docs/CLIENT-BOUNDARY-AND-LEAK-REPORT.md](https://github.com/rumpelpalmour757-lgtm/cross-platform-privacy-environment-kit/blob/v0.4.0/docs/CLIENT-BOUNDARY-AND-LEAK-REPORT.md)。
- **零依赖离线交互展示台 UI**：新增 [docs/index.html](https://github.com/rumpelpalmour757-lgtm/cross-platform-privacy-environment-kit/blob/v0.4.0/docs/index.html)，同时支持 GitHub Pages 在线浏览与本机离线打开，内置路由 JSON 生成器、Windows 断网开关与 LAN DNS 规划器（含 DHCP 必填校验与补集区间实时计算）、持久化隐私自检清单、原创报告浏览器，以及协作伙伴 **哈基米（Gemini）** 署名与互动小助手。
- **自动化测试与工程卫生**：新增 GitHub Actions（Linux Python 3.10/3.13 + Windows Python 3.13）自动测试与发布工作流，完整保留并扩充离线单元测试套件。

## 附件说明

- `cross-platform-privacy-environment-kit-v0.4.0.zip`：干净开源完整包（不含 `.github/`、`tools/` 等仓库维护文件）。
- `LICENSE` 与 `THIRD-PARTY-NOTICES.md`：随包附带的许可与外部参考声明。
