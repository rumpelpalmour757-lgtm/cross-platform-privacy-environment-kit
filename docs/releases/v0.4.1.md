# v0.4.1 — 统一三态体检单与工程边界补强

本版本面向只读诊断体验与工程透明度升级，把客户端边界审计、三态核验摘要与可打印离线 HTML 体检单整合进统一入口，并补全三项易被忽略的跨界与外部盲区说明。

## 变更要点

- **统一三态体检与一键离线 HTML 体检单**：`environment_report.py` 自动合并 `audit_client_boundary.py`，输出 10 项三态摘要（`pass` / `gap` / `unknown`）与三层证据分级，并支持 `--html-out` 一键导出零外部 CDN、支持打印存 PDF 的单文件离线体检单（自动防符号链接写入与 HTML 注入转义）。
- **本地 MCP 桥接只读脱敏盘点**：`audit_client_boundary.py` 新增 `localMcpBridges` 只读计数（不输出服务器名称、命令、参数或密钥），提醒复核可能读取宿主机时钟或文件系统的本地桥接服务。
- **工程边界与盲区显式化**：在 [PRIVACY-CHECKLIST.md](https://github.com/rumpelpalmour757-lgtm/cross-platform-privacy-environment-kit/blob/v0.4.1/PRIVACY-CHECKLIST.md)、[docs/CLIENT-BOUNDARY-AND-LEAK-REPORT.md](https://github.com/rumpelpalmour757-lgtm/cross-platform-privacy-environment-kit/blob/v0.4.1/docs/CLIENT-BOUNDARY-AND-LEAK-REPORT.md)、[CLAUDE-PROXY-OPTIMIZATION-GUIDE.md](https://github.com/rumpelpalmour757-lgtm/cross-platform-privacy-environment-kit/blob/v0.4.1/CLAUDE-PROXY-OPTIMIZATION-GUIDE.md) 及交互工作台 [docs/index.html](https://github.com/rumpelpalmour757-lgtm/cross-platform-privacy-environment-kit/blob/v0.4.1/docs/index.html) 中，补齐「出口 IP 历史信誉盲区（`unknown`）」「本地 MCP 跨界自查」与「网络层零泄露 ≠ 虚拟化/运行态无异常」的客观工程对照。
